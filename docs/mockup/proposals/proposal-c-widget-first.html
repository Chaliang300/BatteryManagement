优点「勾选」被翻译成「把设备放进挂件」这个动作，语义最直白；改动即时反映在预览上，不用切页核对；Dock 放三档尺寸，比藏在设置里更好找。
代价主界面把最优位置给了一个盒子，电量列表退居第二页；设备多到 12 台以上时，芯片会长成两排半，「在 / 不在」需要扫视。
适合用户主要诉求就是「让挂件显示我想看的那几台」；如果产品定位是「电池仪表盘」，这一版会把主次搞反。

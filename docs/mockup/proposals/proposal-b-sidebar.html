优点信息密度最高：一屏同时看到全表 + 单台详情；勾选与详情分成「行首 / 右侧」两个入口，不打架；符合 Windows 用户对「设置面板」的预期。
代价三栏把窗口吃到 900×620，列表只剩约 380px，长设备名要截断；Dock 在这里只是快捷条，存在感弱，容易被认为是多余的一层。
适合设备偏多（12 台以上）、需要逐台调别名/提醒开关的重度用户；也最容易和 `settings.json` 的字段一一对上。

**三份都是独立 HTML，互不依赖，直接双击打开即可操作。**

| 文件 | 方案 | 一句话 |
| --- | --- | --- |
| `proposal-a-dock.html` | **A · 底部 Dock 导航** | 没有侧栏，Dock 就是导航；设备用卡片网格，勾选在卡片右上角 |
| `proposal-b-sidebar.html` | **B · 侧栏 + 检查器** | 左导航固定目的地，勾选在行首，选中行的详情在右侧检查器 |
| `proposal-c-widget-first.html` | **C · 组件工作台** | 打开就是挂件预览，下面两排设备芯片，勾选 = 把设备放进/拿出挂件 |

---

## 一、怎么对比

三个页面都支持：

- **真实切页**：点导航（A 是底部 Dock / B 是左侧栏 / C 是顶部页签）切换视图，不是静态图。
- **勾选联动**：勾选设备，标题栏计数、组件预览、芯片/脚注同步变化。
- **深浅切换**：页面左上角「切到浅色」，整个窗口的 token 一起换。

建议按这三步看：

1. 进「设备 / 设备管理」页，找勾选框在哪、顺不顺手；
2. 进「组件」页，看勾选后预览有没有立刻变化；
3. 进「设置 / 外观」页，判断设置是该独立一页，还是能塞进侧栏。

## 二、结构差异

| | A · 底部 Dock | B · 侧栏 + 检查器 | C · 组件工作台 |
| --- | --- | --- | --- |
| 导航模型 | 底部胶囊 Dock，4 项 | 左侧固定竖栏，4 项 | 顶部页签，3 项 |
| Dock 的作用 | 导航（唯一入口） | 快捷条（显示挂件 / 隐藏 / 刷新） | 三档尺寸切换 + 托盘开关 |
| 设备呈现 | 4×2 卡片网格 | 表格式列表 | 单列表 + 状态列 |
| 勾选在哪 | 卡片右上角圆形开关 | 行首 16px 方框 | 行首方框 + 芯片上的 × / ＋ |
| 单台详情 | 无独立详情（卡片信息够用） | 右侧 286px 检查器 | 底部操作条（别名 + 置顶 / 忽略） |
| 组件预览 | 独立页，左侧清单右侧预览 | 独立页，右侧固定预览 | 首屏主体，随勾选实时变 |
| 设置 | 与外观合并在「设置」页，两栏 | 外观、设置分成两页，单列表单 | 「设置」一页三块面板 |
| 窗口尺寸 | 880×600 | 900×620 | 860×660 |

## 三、取舍

**A 底部 Dock**
- 内容区全宽，8 台设备一屏排开，纵向利用率最高；Dock 只占 54px。
- 代价：Windows 用户不熟底部导航，点完 Dock 鼠标得跑回上半屏；目的地超过 5 个就塞不下。

**B 侧栏 + 检查器**
- 信息密度最高，一屏同时看到全表 + 单台详情；勾选（行首）和详情（右侧）两个入口不打架。
- 代价：三栏把窗口吃到 900×620，名称列只剩约 200px；Dock 在这里存在感弱，容易被问「这层是干嘛的」。

**C 组件工作台**
- 「勾选」被翻译成「把设备放进挂件」，语义最直白；改动即时反映在预览上，不用切页核对。
- 代价：主界面最好的位置给了一个盒子，电量列表退到第二页；如果产品定位是「电池仪表盘」，这一版主次是反的。

## 四、三份共用的东西（合并时不用重做）

- **颜色 token**：`--accent` / `--ok` / `--warn` / `--danger` / `--t1…t4` / `--hair` / `--track` / `--fill`，深浅两套同源。
- **电量阈值判据**：<20% 红、20–40% 琥珀、其余中性；充电中绿色覆盖阈值；品牌色只用于交互与选中。
- **窗口圆角 8 DIP**：DWM 只有 0 / 4 / 8 三档。挂件预览也按 8 画——这是刻意的，和主窗口同一条约束。
- **样例数据**：8 台设备（5 台在组件、1 台充电中、1 台离线），与 `docs/mockup/index.html` 的 02 章节一致。
- **状态语义**：在线 / 离线 / 未知（空心环）/ 充电中，四态在列表里都能看到。

这几条要等你选完方案再定，现在三份都是各写各的：

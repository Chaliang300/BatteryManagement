浅色版不透明度锁在 0.86 是刻意的地板值：Windows 壁纸不可控，低不透明度会被深色或高饱和壁纸染成灰紫。 另外：品牌色只用于交互与选中（筛选、链接、选中行左侧竖条），不再用于表达电量高低—— 上一版把「最低电量」画成品牌蓝，和托盘电量环的红 / 琥珀告警是两套语言。

电量阈值（与托盘电量环共用一套判据）

区间含义表现
< 20%需充电百分比与条用告急色，触发低电量通知（默认 20%，30 分钟内不重复）
20% – 40%偏低百分比与条用偏低色，不通知
40% 以上正常条用中性填充，百分比用一级文字色
充电中—绿色 + 闪电图标，覆盖上面三档：正在充电的设备不该被标成告急
未知数据源不可用空心状态环，电量位显示「—」，不按趋势外推

阈值写死在这里，是为了让列表、挂件、托盘三处用同一套判据。改阈值要三处一起改。

03 · CONNECTION STATE

在线 / 离线

状态点落在行首，4 / 5 / 6 px。在线绿、离线灰；离线行整体降到 50%，并把电量改为「—」—— 旧读数不可信，不能当数据展示。

状态三态 · STATE

在线 ONLINE

已连接，且读数在有效期内。正常渲染，不做任何弱化。

离线 OFFLINE

整行 50%，电量位显示「—」。恢复后不重排，位置不变。

未知 UNKNOWN

启动首帧或数据源不可用。空心环，不用灰色实心 —— 它不是离线。

行内落位 · IN ROW

  • MX Master 3S 23%
  • 触控笔 —

为什么点放行首、不做整行变色：链路图标已表达「无线 / 有线」，再上色会与电量条的品牌蓝打架； 整行填充成绿或灰，会让等权重布局出现新的视觉主角。一个 5px 的点是唯一不改变既有层级的加法。

状态来源 · SOURCE

链路判据延迟
蓝牙 ConnectionStatus + GATT 读失败计数 即时
2.4G 接收器 HID 心跳，连续 3 次超时 45–60s
USB PnP 设备在场 + 句柄仍有效 即时
本机 WMI BatteryStatus，无电池则不列入 60s

更新策略 · REFRESH

  1. ① 事件优先蓝牙 / USB 的连接变化走系统事件，不等轮询，几百毫秒内到位。
  2. ② 心跳兜底2.4G 接收器没有系统事件，靠应用内 15s 一次 HID 读取探活。
  3. ③ 可见才跑挂件被遮挡或最小化时暂停采集，重新可见时立刻补一次。
  4. ④ 300ms 合并蓝牙抖动期内的多次状态变更合并成一次渲染，避免反复闪。
online = now - lastEvent < 90s
      && now - lastRead  < 90s

// 两个条件缺一不可：系统说连着、
// 但读数停滞，就是僵尸连接，按离线处理。

切换效果 · TRANSITION

  1. 0 ms收到 Disconnected 事件，立即锁定该行，不让它继续参与排序。
  2. 150 ms状态点交叉淡化：绿 → 灰，同位置换色，不缩放。
  3. 280 ms百分比淡出、横线淡入，各 120ms，中间留 40ms 空窗避免字符叠影。
  4. 300 ms整行落到 50%，稳态。行高不变，列表不重排。

反向恢复时故意错开：先恢复行不透明（120ms），再让点变绿（再 200ms）。 同时做会像「弹回来」，抢走对其它行的注意力。

异常处理 · EDGE CASES

已配对未连接（合盖 / 超距）
判离线。悬停可看「最后 64% · 12 分钟前」，不把旧值当当前值。
无蓝牙适配器 / 服务未启动
空心环，不判离线。功能不可用 ≠ 设备掉线。
僵尸连接（报连上但读数停滞）
90s 无更新即判离线。宁可少显示，也不显示一个不会变的数字。
全部离线
页眉显示 0/N，组件整体 65%。不弹错误、不显示空状态插图。
采集异常（读取失败但设备在）
重试 3 次仍失败降为未知态，保留上一次已知电量，不清零。

04 · APP ICON & TRAY

图标里是满格，托盘里是实况

一个壳里三个电芯 = 多台设备聚合成一个读数，格数就是档位。同一个形状，两种语义： 图标表示身份，托盘表示状态。

应用图标 · APP ICON

按尺寸换描边档：256 / 64 用 11，32 用 14 并把三格合并，16 用 24 加粗。 缩小不是等比缩放，是补偿亚像素损失。

托盘图标 · 深色任务栏

托盘图标 · 浅色任务栏

左 → 右：正常 ≥50% · 中 20–49% · 低 <20% · 充电中。 绿色只表示「正在充」，不表示满；浅色任务栏整枚反色并降明度。

这块面板的四条规则

  1. 勾选即入组件，取消即刻移除，无二次确认 —— 组件改动是可逆的。
  2. 勾选数量决定密度：≤3 台时大号自动放大行高；5 台是中号上限，7 台是大号上限。
  3. 排序与显示内容是两个独立维度，互不联动；手动模式下列表可直接拖拽。
  4. 改动在点「完成」前不落盘，写入 settings.json。

07 · DESKTOP SCENE

落在 Windows 桌面上

无边框透明窗口（WS_EX_TOOLWINDOW | NOACTIVATE），可拖动、右键出菜单、不占 Alt+Tab。 材质跟随系统主题，否则深色桌面上会贴一块白板。

壁纸为渐变模拟。真实环境中窗口背景模糊会采样壁纸像素，因此同一块玻璃在深色与浅色壁纸上的观感不同。

PowerDock 界面设计还原 · 静态稿，交互仅用于演示状态切换与面板操作。

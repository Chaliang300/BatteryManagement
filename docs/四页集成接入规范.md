# PowerDock 四页并行集成接入规范（S2 基线）

本文档供四个并行开发对话（概览页/集成人、设备管理页、组件页、设置页）共同遵守。
**集成人**负责主窗口外壳接线、导航状态机与四页生命周期管理；各单页对话负责各自页面内部视图。

---

## 1. 独占文件与职责分工

| 角色 / 页面 | 分支 | 独占文件 | 职责 |
|---|---|---|---|
| **集成人（主会话）** | `feat/s2-overview-page` | `MainWindow.cs`、`MainWindow.*.cs`、`App.cs`、公共接线 | 维护导航状态机、外壳生命周期、快照分发、各页挂载入口、跨页定位路由 |

**硬规矩**：除集成人外，另外三个对话**严禁直接修改** `MainWindow.cs`、`MainWindow.DeviceContent.cs`、`App.cs`。如需主窗口挂载新视图，请提供标准接口，由集成人统一挂载。

## 2. 页面注册与生命周期契约

1. **唯一宿主与内容槽**：
   - `MainWindow` 拥有唯一的内容宿主 `_contentHost`；
   - 每页对应一个 `MainPageVisual`，包含独立的 `ScrollViewer`、`TitleText`、`ContentSlot`（内容槽）与 `EmptyStateCard`（空态卡片）；
   - 各页通过 `MainWindow.ReplacePageContent(MainPage page, UIElement content)` 注入内容槽；
   - 注入后空态卡片自动折叠，页面标题（`PageTitle`）始终保留，满足外部 UIA 自动化验证契约。

2. **严禁直接替换 `_contentHost.Content`**：
   - 采集线程与快照回调**绝对禁止**直接改写 `_contentHost.Content`；
   - 页面切换唯一由 `MainWindow.NavigateTo(MainPage page)` 调度；
   - 采集回调只更新各页面视图内部的数据（如 `view.Render(snapshot)`），由导航状态机保证用户正在浏览的页面不会被刷新动作踢回其他页面。

3. **每页只初始化注册一次**：
   - 页面实例被缓存复用，切页不重建、滚动位置（`VerticalOffset`）自动保存与恢复。

## 3. 状态快照与持久化唯一源契约

1. **设备快照统一消费**：
   - 统一消费 `AcquisitionHost` 分发的 `IReadOnlyList<DeviceState>` 快照；
   - 严禁各页自行新建 `AcquisitionHost`、`IDeviceProvider` 或采集轮询器。
2. **设置存储统一消费**：
   - 统一使用 `SettingsStore`（`settings.json`）；
   - 写入必须遵循「读 → 改 → 原子写 → 回读校验」原则，回读一致才提示成功；
   - 严禁每页私建设置副本或直接修改磁盘 JSON。

---

## 4. 跨页设备定位接口契约（概览 → 设备管理）

1. **定位接口定义**：
   ```csharp
   public interface IDeviceLocator
   {
       bool SelectAndScrollToDevice(DeviceKey key);
       bool SelectAndScrollToDevice(string key);
   }
   ```
2. **联动调用链路**：
   - 用户在概览页点击设备条、焦点卡或异常行；
   - 概览页触发 `MainWindow.NavigateToDevice(key)`；
   - `MainWindow` 先切换至 `MainPage.Devices`，随后调用设备页的 `IDeviceLocator.SelectAndScrollToDevice(key)`；
   - 设备页选中该设备卡片（accent 描边）并将其平滑滚动到可是区域内。

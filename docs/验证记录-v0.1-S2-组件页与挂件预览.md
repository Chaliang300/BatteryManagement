## 1. 做了什么

1. **契约文档先行（`AGENTS.md`）**：
   - §5.3.0 确立设置存储模型契约：新增 `AppSettings.WidgetDevices` (`List<string>`)，存储物理设备键 `DeviceKey.Value`；
   - 确立正交独立契约：组件勾选（`WidgetDevices`）、置顶（`PinnedDevices`）和忽略（`IgnoredDevices`）三者各自独立维护，互不推导也不互相覆盖；
   - 锁定旧配置兼容与可靠性：旧版 `settings.json` 缺少 `WidgetDevices` 时自动补为空列表；保存失败时原子回滚至上一有效配置，UI 恢复旧值并反馈；
   - §6.3 / §6.5 细化组件页与 1:1 挂件预览规格：
     - 小 2×2: 173×173 DIP, r22, pad14, 最多 3 行；双行布局（点/名称/百分比，第二行满宽条），居中紧凑 10px 间距；
     - 中 4×2: 362×173 DIP, r27, pad16, 最多 5 行；单行四列；
     - 大 4×4: 362×362 DIP, r27, pad22, 最多 7 行 + 底部唯一汇总脚注（`共 N 台 · M 在线 · 按电量升序 · 空闲 60s 刷新`）；
     - 切尺寸不清空勾选集合；
     - 已勾选离线设备照常显示在挂件中，整行半透明 50%，电量显示「—」；
     - 桌面挂件宿主尚未实现时明确标为预览，并与未来宿主复用同一份 `WidgetRowItem` 投影行数据。

2. **核心业务模型与数据管道（`PowerDock.Core`）**：
   - `AppSettings` 扩展 `WidgetDevices`，更新 `Clone()` 深拷贝；
   - `SettingsStore` 更新 `NormalizeSettings`（null 补空列表）与 `ValidateSettings`（回读双向校验一致性）；
   - `WidgetSizeSpecs`：定义小/中/大三档尺寸宽高、圆角、内边距与最大行数常量，提供与字符串及枚举的互转；
   - `WidgetRowItem`：挂件行渲染只读投影数据，封装 `DeviceKey`、名称、百分比、充电状态、离线标记、链路类型、语义色阶（`Tone`）与条填充比（`FillRatio`）；
   - `WidgetPresentationModel`：挂件全量纯数据模型，包含三档规格、已选数、在线数、总数、行列表、大号脚注与宿主连接状态；
   - `WidgetPipeline`：纯逻辑数据投影管道，执行勾选集合过滤、契约排序（有效电量升序，无电量排末尾，名称升序）、三档容量截断与大号脚注装配。

3. **专属界面与呈现（`PowerDock.App`）**：
   - `WidgetUiTokens`：集中管理深色/浅色语义画刷（Accent, Ok, Warn, Danger, Off, Text1-4, Track, Fill, Hair），全部 `Freeze()`；
   - `WidgetPreviewControl`：1:1 挂件卡片自绘控件，严格按 173×173 / 362×173 / 362×362 DIP 自绘三层材质，外壳硬约束 2（`RectangleGeometry` 裁切子元素防止双层圆角），支持小号双行重排居中、中/大号单行四列、离线设备半透明与破折号、无设备与未勾选空态；
   - `WidgetsPageView`：组件页专属 UserControl，左侧真实设备清单（Checkbox 可勾选、链路标识、名称、电量/破折号、底部已选 N/Total 与容量统计），右侧挂件预览舞台（明确标为预览模式，展示当前规格与 1:1 卡片）；右上角三档 Seg 控制器；保存失败错误横幅提示；订阅 `SettingsStore.SettingsChanged`，无论从设备页、设置页还是组件页修改勾选/尺寸，同源同帧双向联动；
   - `MainWindow.WidgetsContent.cs`：主窗口约定挂载点专属分部类，提供 `AttachWidgetsPage` / `RenderWidgets` / `ShowWidgetsPage`，同步更新标题栏「N/Total 在组件」计数，不侵入公共导航与窗口结构。

4. **诊断与系统自检（`PowerDock.App`）**：
   - 新增 `WidgetDiagnostics.cs`，并在 `Program.cs` 接入 `--diagnose-widgets` 命令；
   - 在 `SelfTestRunner.cs` 新增 `WIDGET-01` 自检项，自检总项数由 15 项增至 16 项（16/16 全部通过）。

## 3. 哪些没验

1. **真实桌面独立悬浮窗口（`WidgetWindow`）**：本 PR 只负责组件页（`WidgetsPageView`）及其 1:1 预览（`WidgetPreviewControl`），桌面独立挂件宿主（无边框透明窗口、贴边 12px 吸附、Alt+Tab 隐藏等）属于挂件宿主专项，当前在组件页明确标注为「预览模式」；
2. **多显示器混合 Per-Monitor DPI 动态拖拽**：在自动化量测中验证了 100% 与 150% DPI 下各档位布局计算严格无溢出，但尚未验证主窗口在双屏间动态拖拽且两屏 DPI 不一致时的瞬时重绘表现；
3. **设备管理页（Devices Page）全量卡片网格渲染**：本 PR 验证了 `SettingsStore.SettingsChanged` 事件驱动下的勾选双向联动及标题栏计数一致性，但设备页 4 列卡片自身的排版与操作栏由设备页负责人独立开发交付。

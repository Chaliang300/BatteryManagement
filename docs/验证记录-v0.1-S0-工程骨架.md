## 一、做了什么

1. **工程骨架与构建链 (PR-S0-01)**：
   - 搭建 `src/PowerDock.Core`（通用契约模型、存储与调度抽象、1MB 滚动日志）与 `src/PowerDock.App`（外壳生命周期、互操作与诊断）工程目录体系；
   - 编写 `build.ps1` 与 `pack.ps1`，提供自动化编译与打包脚本，生成 win-x64 免安装压缩包（**当前实现为 .NET Framework 4.8 IL 程序，不满足 D16；.NET 10 自包含发布基线另行重做**）；
   - 添加 `app.manifest` 与 `PowerDock.exe.config`，保证 Windows 10/11 操作系统兼容与高 DPI 适配；
   - 排除二进制产物与本地临时数据，更新 `.gitignore`。

2. **设置持久化存储 (PR-S0-02)**：
   - 实现 `AtomicFile`：写入 `.tmp` 临时文件、完整性回读校验、`File.Replace` 原子替换并自动生成 `.bak` 备份；
   - 实现 `SettingsStore`：提供基于 JSON 序列化的配置持久化，执行「读 -> 改 -> 写 -> 磁盘回读校验」闭环，校验失败或写盘异常自动回滚内存与磁盘配置；
   - 补齐默认设计配置基线（中号 362×173 DIP、深色主题、20% 告警阈值、30 分钟冷却）。

3. **单实例互斥与前台防截流 (PR-S0-03)**：
   - 实现基于用户会话隔离的命名互斥体（`Local\PowerDock_Mutex_{SessionId}`）与命名管道（`PowerDock_Pipe_{SessionId}`）；
   - 主实例后台监听激活信号并转移前台；第二实例发起 `activate` 短连接后自动转交前台权限并优雅退出；
   - 封装 Win32 P/Invoke（`AllowSetForegroundWindow`、`SetForegroundWindow`、`FlashWindowEx`），当系统拦截置前时自动降级为任务栏闪烁提醒。

4. **开机自启与系统托盘服务 (PR-S0-04)**：
   - 实现 `AutoStartService`：操作 `HKCU\Software\Microsoft\Windows\CurrentVersion\Run`，带双引号参数，写入与删除均执行实时回读校验，杜绝键值残留；
   - 实现 `TrayIconService` 与 `BatteryTrayIconRenderer`：动态绘制 16/20/24/32px 四档分辨率下的三格电池托盘图标（正常白/墨色、低电量橙、充电绿、离线灰五态），覆盖深浅任务栏反色；
   - 托盘初始化失败时记录 Warning 并标记降级状态，窗口关闭时直接退出应用，避免生成隐形僵尸进程。

5. **主窗口规格与自检闭环 (PR-S0-05)**：
   - 实现 `MainWindow`：严格锁定 880×600 DIP，44 DIP 标题栏可拖动，底部 44 DIP 胶囊 Dock 导航，内容区底部留白 84 DIP 为 Dock 让位；
   - 实现 `DwmHelper`：基于 Windows 11 Build 22621+ 原生能力注入 DWM 8 DIP 圆角（`DWMWCP_ROUND`）与 Acrylic 材质背景（`DWMSBT_TRANSIENTWINDOW`），执行 DWM 帧扩展与 `SWP_FRAMECHANGED` 刷新；
   - 扩展内置自检 `SelfTestRunner` 覆盖 14 项自检，格式化输出 `data/self-test.json`。

## 二、怎么验的

### 1. 构建与打包验证

- **构建命令**：`powershell -NoProfile -ExecutionPolicy Bypass -File .\build.ps1`
  - 结果：成功编译 15 个 C# 源码文件，产出 `PowerDock.exe`（**67,072 B**），exit 0，0 警告 0 报错；
  - 复现：qa-release 在 `git clone` 的干净检出（HEAD `bc822b5`）上重跑，结果一致（临时目录验后已删）。
- **打包命令**：`powershell -NoProfile -ExecutionPolicy Bypass -File .\pack.ps1 -Version 0.1.0 -Zip`
  - 结果：生成 `dist/PowerDock-v0.1.0-win-x64.zip`，体积 **32,562 B（`pack.ps1` 自报 31.8 KB）**；
  - 包内容：`PowerDock.exe`(67,072 B) + `PowerDock.exe.config`(290 B) + `LICENSE` + `README.md`，共 4 条目；
  - **该包不是单文件自包含包**：其中没有任何 .NET 运行时，exe 是 .NET Framework 4.8 IL 程序，运行期需加载系统 `Framework64\v4.0.30319\clr.dll`。
  - 旧版本记录此处写「14.8 KB」为错误数字，已订正（见 §五 第 3 条）。

### 2. 自动化内置自检验证

- **执行命令**：`.\PowerDock.exe --self-test`（**必须放在工作区外运行**，工作区内 exe 会被沙箱降权导致托盘注册 Win32=5）
- **输出结果**：14 项自检全部通过（Total: 14, Passed: 14, Failed: 0）。
- **复跑记录（qa-release，`%LOCALAPPDATA%\Programs\PowerDock-qa\`）**：total=14、passed=14、failed=0、exit=0；进程寿命 382.979 ms（`StartTime`→`ExitTime`）；输出 `data/self-test.json` 3,766 B；仓库内 `data/self-test.json`（3,714 B）未被覆盖。

> **重要口径（本轮新增）**：以下 14 项是 `--self-test` 的**自检项结果**，只代表每条断言在其代码路径上成立。
> 它**不等于**对应验收口径通过——例如 `MUTEX-01`/`PIPE-01` 是同进程测试、`WIN-01` 只读到自设属性、`PERF-01` 只断言内存。
> 判定见 [`docs/验收矩阵-v0.1-S0.md`](验收矩阵-v0.1-S0.md)：25 行中 10 通过 / 10 未验证 / 5 失败。

自检项清单（`Passed` 仅代表该项断言成立）：

- `SYS-01`: 64 位进程运行环境（Passed）
- `SYS-02`: Windows 10/11 操作系统版本检测（Passed；判据仅 `osMajor>=10`，不区分 Win11）
- `CORE-01`: `DeviceKey` 与 `ReadingKey` 大小写不敏感哈希与比较（Passed）

- `FS-02`: `AtomicFile` 原子覆盖替换与 `.bak` 备份机制（Passed）

- `TRAY-01`: 四档五状态托盘位图渲染与句柄释放（Passed；**仅校验尺寸与句柄，无像素断言**）

- `WIN-01`: 主窗口规格（Passed；只读回自设的 `Width/Height/MinWidth/MinHeight`，未 Show 窗口）
- `PERF-01`: 内存占用 < 150MB（Passed；`perfPassed` 只含内存判定，`uptime` 仅打印）

## 三、哪些没验

1. **冷启动首帧**：未测量。`--self-test` 路径不创建窗口，现有 383 ms 是进程运行时长，**不得当作首帧**。需在 `Main` 打点至首个 `CompositionTarget.Rendering`，并记录机型、构建类型与轮次。
2. **Acrylic 实际呈现与降级**：仅有 Build≥22621 的能力探测。本机壁纸近纯黑，像素判据无法区分「材质生效」与「实色底」；降级分支（能力不足 / 系统透明效果关闭）从未执行。
3. **托盘图标实际可见性**：UIA 枚举通知区可见项无 PowerDock（Windows 11 新图标默认进溢出区）；`IsTrayAvailable=true` 只代表 `_notifyIcon.Visible` 未抛异常。需 `Shell_NotifyIconGetRect` 级证据。
4. **置前被拒反馈**：`FlashWindowEx` 封装存在但拒绝场景从未构造、未观测到闪烁。
5. **无 .NET 运行时的干净机启动自包含包**：本机有 `WindowsDesktop 10.0.11` 共享运行时且已装用户级 SDK `10.0.403`，无法充当证据；当前包本身也依赖 .NET Framework 4.8。需一台无运行时的 Windows 机器或可用 VM。
6. **真实登录自启（产品值 `PowerDock`）**：自检只操作唯一测试值，登录后实例数、窗口隐藏状态均未验证。
7. **设置写入失败回滚**：`SettingsStore.Rollback` 有实现，但无任何测试覆盖失败路径（只读文件、占位句柄、满盘）。
8. **D7 的 xUnit 轨**：`tests/` 为空，单测轨尚未建立。
9. **真实外设蓝牙/HID 链路采集**：BLE GATT、HID 报告解析与 WMI 采样将在 **S1 采集与状态阶段** 接入并执行 5 分钟连续稳定性测试。
10. **多显示器与多 DPI 拖拽**：挂件 173/362 DIP 切换、贴边 12px 吸附及跨 DPI 渲染将在 **S2 界面与一致性阶段** 验证。
11. **长期运行稳定性与 7 天趋势**：5 分钟桶日滚动 JSONL 与 7×24 句柄无泄漏测试将在 **S3 完善与发布候选阶段** 开展。

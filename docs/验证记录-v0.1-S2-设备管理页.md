## 1. 做了什么

1. **契约文档先行更新（AGENTS.md）**：
   - 更新 §6.5 设备管理页规格：定义四列卡片网格解剖（组件勾选圆点、链路图标与细分、设备名称/别名、大字百分比与充电指示、电量条、脚注与读数时效、离线显示上次读数、按 DeviceKey 选中）；
   - 细化底部操作条（别名/置顶/忽略/查看详情）持久化契约，明确「读 → 改 → 原子写 → 磁盘回读校验」一致才更新 UI 状态；
   - 增加防串选状态保持与跨页定位接口契约（实现 `IDeviceLocator`）；
   - 在 §18 变更记录中登记更新条目，全文控制在 394 行（满足 ≤ 480 行约束）。

2. **纯矢量链路与状态图标（`DeviceIcons.cs`）**：
   - 纯矢量 `DrawingImage` 绘制，自适应任意 DPI 缩放，避免位图抗锯齿虚化；
   - 包含：蓝牙符文（15×15 DIP）、2.4G 同心弧与点（15×15 DIP）、USB 有线主干箭头分支（15×15 DIP）、本机笔记本轮廓（15×15 DIP）、未知外设（15×15 DIP）、充电闪电 ⚡（12×12 DIP）及未发现设备空态大图标（48×48 DIP）。

3. **四列设备卡片控件（`DeviceCardControl.cs`）**：
   - 右上角组件勾选圆点（19×19 DIP，圆形，未选边框透明底，勾选 `--accent` 蓝底白对勾）；
   - 链路细分严格遵循 §5.3.1：精准区分「USB 有线已确认」、「USB 设备，连接方式待确认」、「2.4G HID」、「接收器已连接，外设状态未知」、「蓝牙 GATT」、「蓝牙（已配对，未连接）」及「连接方式未知」；
   - 电量与充电呈现：真实 0% 正常显示「0%」，缺失显示「—」；根据状态着色（危险红 <20%、警示橙 20–40%、正常白、充电绿 `--ok`、离线灰 `--off`）；充电中附带 ⚡ 充电指示；
   - 进度条（4 DIP 高度，圆角 2 DIP，背景 `--track`，填充随语义色）；
   - 脚注：`在组件中 · 2.4G HID` / `未显示 · 蓝牙 GATT` / `离线 · 上次 82% · 10分钟前`；
   - 离线设备整卡半透明 50%（`Opacity = 0.5`）；
   - 选中态：`--accent` 描边 + `--accent-soft` 淡底，不用实色填充。

4. **设备管理页面视图（`DeviceSummaryView.cs`）**：
   - 复用现有 `DeviceSummaryView` 与 `Render(IReadOnlyList<DeviceState>)` 入口，实现 `IDeviceLocator`；
   - 明确空态（Empty State）：无设备时居中显示大图标、「未发现设备」标题以及蓝牙开启/配对与 USB/2.4G 接收器插入双指引，绝不显示 0%；
   - 四列等宽响应式网格（`new GridLength(1, GridUnitType.Star)`），行间距与列间距像素对齐；
   - 底部提示栏（hintbar）与操作条（actbar）：支持别名编辑保存、置顶/取消置顶、忽略/取消忽略与查看详情诊断日志；
   - 持久化控制：所有操作均通过 `SettingsStore` 原子写并回读成功才在 UI 呈现；失败回滚；
   - 防串选与状态保持：以物理设备键 `DeviceKey` 记录选中项，在 200ms 合并、轮询或切页返回时，基于 `DeviceKey` 保持选中状态与滚动位置；同型号同名设备绝对独立，互不串选；
   - 跨页定位接口：实现 `SelectAndScrollToDevice(DeviceKey)` 与 `SelectAndScrollToDevice(string)`，供概览点击跳设备页时自动高亮并滚动到可视区域。

5. **概览接口约定与持久化接入**：
   - 在 `MainWindow.DeviceContent.cs` 中增加 `SelectDeviceCard(DeviceKey)` 和 `SelectDeviceCard(string)` 供概览负责人调用；
   - 在 `SettingsModel.cs` 和 `SettingsStore.cs` 中扩展并校验 `WidgetDevices`，保证组件勾选接入同一份持久状态源，提供 `TrySetDeviceAlias`、`TryTogglePinnedDevice`、`TryToggleIgnoredDevice`、`TrySetWidgetSelected` 安全持久化操作方法。

## 3. 哪些没验

1. **极度满盘（ENOSPC）极端环境下的磁盘原子写回滚**：已用常规只读与 ACL 校验持久化回滚，但未在 0 字节剩余空间的物理磁盘分区下实机拔插。
2. **超过 100 台以上外设海量列表下的虚拟化流畅度**：主窗口设备管理页针对桌面典型外设规模（8–16 台）设计，采用带滚动条的等宽网格，未开启 `VirtualizingStackPanel`。
3. **真实触控屏手势拖动惯性**：在 Windows 11 x64 桌面实机环境下通过鼠标滚轮、点击与焦点测试，未在 Surface 等触摸屏设备上进行物理多点触控与惯性测试。

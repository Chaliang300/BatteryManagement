# v0.1 工程基线验证记录

日期：2026-11-08

## 做了什么

- 补齐发布基线、采集协议、设备身份与来源裁决、调度时效、数据落盘、Windows 外壳与验收规则。
- 同步工程设计，登记离线详情、中档高度和预览圆角的原型差异。
- 增加项目入口和 Git 换行、忽略规则，沿用远端已有的 MIT 许可证与提交历史。

## 怎么验的

- 用 `node --check docs/mockup/app.js` 检查当前原型脚本语法。
- 用 Node 执行原型事件处理代码，确认点选离线 Watch S9 时会显示 `0% · 刚刚更新`，切到中档时脚本清空高度。这两项是已登记的原型差异。
- 检查文档入口、原型资源路径、Git 暂存文件清单与空白错误。`.workbuddy/` 和运行、构建产物由忽略规则排除。

## 哪些没验

- 当前没有 WPF 源码、测试或自检入口，本机未检测到 .NET SDK。发布包体、冷启动、采集协议、单实例、托盘、Acrylic 和多屏 DPI 在对应实施阶段实测。
- 本轮采用静态与脚本级检查。无头浏览器受环境限制，实际布局及 Ardot 源稿仍待核查。

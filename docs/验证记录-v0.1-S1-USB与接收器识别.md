## 1. 做了什么

1. **只读 HID / SetupAPI / CM 互操作（`HidInterop.cs`）**：
   - 严格对齐 `hidpi.h` 结构布局：`HIDP_VALUE_CAPS` 逐字段声明（包含 `UnitsExp`、`Units`、`LogicalMin/Max` 与末尾联合体），布尔字段显式指定 `[MarshalAs(UnmanagedType.U1)]`，避免 4 字节默认布尔导致逻辑范围错位。
   - 互操作仅使用只读 API：`HidD_GetFeature`、`HidD_GetInputReport`、`HidP_GetCaps`、`HidP_GetValueCaps`、`HidP_GetUsageValue`；禁止任何写操作与私有通道写入。
   - 使用 `cfgmgr32!CM_Register_Notification` 监听 `GUID_DEVINTERFACE_HID` 的到达与移除广播。

2. **在场接口枚举与容器归并（`HidDeviceEnumerator.cs`）**：
   - 使用 `DIGCF_PRESENT | DIGCF_DEVICEINTERFACE` 枚举在场 HID 接口，读取设备接口路径、PnP 实例 ID、容器 ID（`DEVPKEY_Device_ContainerId`）、父节点实例 ID（`DEVPKEY_Device_Parent`）、友好名与设备描述。
   - 过滤 Windows 哨兵 GUID（`00000000-0000-0000-ffff-ffffffffffff` 与全零 GUID）：哨兵值不作为容器依据，退回实例/父节点归并，避免虚拟设备被误并为同一台。
   - 解析 VID 与 PID，脱敏接口路径中的硬件序列号段（`\\\\?\\hid#...#<serial>#...` 替换为 `***`）。

3. **标准 HID 电量解析（`HidBatterySelector.cs`）**：
   - 落实 **C8 裁决**：在 Input 与 Feature 的**值能力列表**中查找 `UsagePage=0x06 / Usage=0x20`（Battery Strength）；不再以顶层集合未命中判定设备无电量。
   - 优先选择 Feature 报告（不消费输入流，不干扰鼠标键盘实时操作）。
   - 按设备实际报告的 `ReportID` 切分报告体（支持 `ReportID=0`）；按 `LogicalMin/Max` 范围线性归一化到 0–100 并夹紧；支持 1–32 位小端多字节原始值；真实 0% 是有效读数。

4. **单端点安全探测（`HidBatteryProbe.cs`）**：
   - 每次探测独立建立短连接打开句柄，读取完成后显式释放句柄与 PreparsedData，避免句柄泄漏。
   - 明确失败分类：无字段（`NoStandardBatteryUsage`）、被系统独占/权限不足（`AccessDenied`）、超时（`Timeout`）；无论是否可读，均保留已发现的设备条目，电量显示「—」。

5. **HID 采集 Provider（`HidDeviceProvider.cs`）**：
   - 实现 `IDeviceProvider`（`ProviderId = "hid"`）。
   - 按容器 ID 归并同一复合设备的多个 HID 接口，同设备仅生成一个物理条目；每个接口的电量能力独立生成 `ReadingKey`。
   - 严守链路判据：端点自身为 USB 实例才标「USB 有线」；仅能确认父节点在 USB 总线时标 `Unknown` 且文案「USB 设备，连接方式待确认」；接收器证据不足时不妄断 2.4G 在线。
   - 刷新操作按 `ReadingKey` 使用 `SemaphoreSlim` 串行化；枚举会话更新后丢弃旧会话迟到结果。

### 2.2 本机硬件实机探测（L3 冒烟）

环境：ASUS TUF Gaming F15 (FX507VV)，Windows 11 Build 26220。
- 枚举到在场 HID 接口共 20 个（包含 `VID_24AE PID_1849` 2.4G 接收器多接口、`ASUF1204` 触摸板多接口、`GVINPUT` 等）。
- 接收器 `VID_24AE&PID_1849` 的 7 个接口（COL01..06）被正确归并到同一个容器 GUID `5ad7988b-7aba-5850-9f11-ce1d7f90ea3e`，未重复计数。
- 触摸板等 ACPI 设备的无容器哨兵 GUID `00000000-0000-0000-ffff-ffffffffffff` 被成功识别并拦截，按独立实例区分，未发生虚拟设备混并。

## 3. 哪些没验

1. **真实标准 HID 0x06:0x20 电量读取（实机 ≤3s 首读与 5 分钟稳定）**：
   - 本机外设（ROG 笔记本自带触摸板、VID_24AE 接收器）均未暴露标准 `UsagePage=0x06 / Usage=0x20` 值能力，实际探测如实返回 `NoStandardBatteryUsage` 或系统独占 `AccessDenied`。
   - **未验证**（本机硬件缺口，已在 S1 验收清单 §4 声明）。解除条件：外接支持标准 HID 电量的鼠标/游戏手柄。
2. **2.4G 接收器拔插与热重载动态演练**：
   - 注册了 `CM_Register_Notification`，静态发现与移除逻辑已由测试覆盖，但本轮未手动拔出接收器产生物理事件。**未验证**。
3. **厂商私有 2.4G 协议读取**：
   - 本机 `VID_24AE` 接收器的电量位于 vendor 私有集合 `0xFF00`，按项目决策属 P2-2 厂商插件，本 PR 严格执行只读与标准字段约束，不越界实现私有写指令。

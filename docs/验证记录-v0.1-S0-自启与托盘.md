## 一、做了什么

1. **托盘注册根因修复（`TrayIconService.cs`）**
   - `Initialize` 顺序改为：创建 NotifyIcon → 右键菜单/事件 → **先渲染并赋 `_notifyIcon.Icon`** → tooltip → `Visible=true`；
   - **`IsTrayAvailable` 语义改为"真实注册成功"**：仅在 `Shell_NotifyIconGetRect` 返回非零矩形后置 true；删掉"`Visible=true` 未抛异常即成功"的推断；
   - 注册校验：枚举本进程 `WindowsForms10.*` 窗口，轮询 uID 0..3（WinForms 实测 uID=1）、重试 3×100ms/总 1500ms，失败记录 HRESULT/Win32 码与原因；
   - `UpdateState` 守卫改为 `_disposed || _notifyIcon == null`（允许 Visible 前赋 Icon）；注册失败时 `Visible=false` 并返回 false。
2. **关窗即退出（S0-TRAY-03）**
   - `MainWindow.OnWindowClosing`：`IsTrayAvailable=false` 时显式 `Application.Shutdown()`，不再只记录日志；`TrayIconService.HandleMainWindowClosing` 同语义保留；
   - 新增诊断入口 `--diagnose-tray-failure`：注入托盘失败 + 900ms 后自动关主窗，用于**进程级**验证"关窗即退出"。
3. **托盘几何规格修正（S0-TRAY-02，规格缺陷）**
   - 24px 基准 `barX={4.1,9.2,14.3}`、gap 1.5（原 0.7）；16px **显式档** `cellW=2.10 / gap=1.45 / barX={2.73,6.28,9.83}`，**禁止等比缩放**（等比后 0.47px 缝会融成一条）；
   - 20/28/32：`cellW=2.80/4.20/4.80`、gap `1.40/1.75/2.00`；`BatteryTrayIconRenderer.GetGeometry(size)` 暴露几何供自检与像素断言复用；
   - **AGENTS.md §6.8** 写入显式几何表与像素判据，§18 记一行（D14 三格形态不变，仅修亚像素间距）。
4. **像素断言（自检 `TRAY-01`，直调 `RenderBitmap`，不抓屏）**
   - 5 档 × 5 状态（16/20/24/28/32 × 正常/充电/低电/离线/浅色）共 25 幅；
   - 判据：中间行相邻格之间**至少 1 列 alpha<64**；最右列 alpha=0（右空档）；语义色 RGB（白 / `#FF9F0A` / `#34D399` / `#8A8F99`）；未点亮格 alpha≈0.14（实测 34–36）；GDI 句柄获取/释放 15 次。
5. **自启与自检（S0-AUTO-03）**
   - `SelfTestRunner.AUTO-01` 改为 `try/finally`：无论读取/校验是否异常，必定执行 disable + 回读清理；
   - 新增 `AutoStartService.CleanupLeftoverTestValues()`：删除 HKCU `Run` 下 `PowerDock_AutoStart_Test_*`；`Program.Main` 与自检启动时调用；
   - `FS-01` 描述改为"数据目录写入/读取/删除闭环测试（原子覆盖由 FS-02 验证）"，与实现一致（原因：该用例从未实现原子替换，原子覆盖由 FS-02 负责）。
6. **诊断入口**：`--diagnose-tray`（真实注册 + `GetRect` 结果/uid/窗口类/失败码，写 `data/tray-diagnose.json`，非零矩形才 exit 0）；`--diagnose-tray-failure`（关窗即退出进程级验证，仅供诊断）。

## 二、怎么验的（锁屏下可执行部分）

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\build.ps1     # 0 错误 / 0 警告
dotnet test .\PowerDock.sln                                        # 12/12 通过
PowerDock.exe --self-test                                          # 14/14 通过
PowerDock.exe --diagnose-tray                                      # exit 0, GetRect 非零
PowerDock.exe --diagnose-tray-failure                              # 进程退出 + 无残留
```

- **自检**：14/14；`TRAY-01` Detail = "5 档 × 5 状态渲染 (25 幅) 像素断言全部通过；句柄释放闭环 (15 次)"；`TRAY-02` 正常初始化 + 菜单结构 + 失败降级分支通过；`AUTO-01` 通过并含 `try/finally`。
- **`--diagnose-tray`（锁屏会话实测）**：`initialized=true`、`GetRect=(2124,1368)-(2172,1440) 48x72`、`uid=1`、`windowClass=WindowsForms10.Window.*`、exit=0 → **托盘图标已真实注册**（此前 15 窗口×uid 0..1023 零命中的缺陷已修复）。
- **`--diagnose-tray-failure`（进程级）**：主窗口自动关闭后进程退出、**exit=0、1583ms、0 条 `PowerDock*` 管道残留、0 进程**；日志 `Tray unavailable. MainWindow closing directly shuts down the application.`
- **AUTO-03 启动清理（真实进程）**：预置 `HKCU\...\Run\PowerDock_AutoStart_Test_0123456789abcdef` → 启动应用 → 值被删除、日志 `Cleaned 1 leftover autostart test value(s) from HKCU Run.`、残留 0。
- 证据：`%LOCALAPPDATA%\Programs\PowerDock-qa\<commit7>\tray-autostart\`（self-test.json、tray-diagnose.json、tray-diagnose-failure.txt、autostart-cleanup.txt、build/test 输出）。

## 三、哪些没验

1. **托盘在任务栏的真实可见性**（S0-TRAY-01 的 UIA 可见项/溢出区确认）：当前会话锁屏，无法可靠枚举交互式通知区；注册本身已由 `GetRect` 非零证明，待解锁后在交互桌面补 UIA 可见性证据。**不据此判 S0-TRAY-01 通过**。
2. **真实 Shell 注册失败**（S0-TRAY-03 的"真实失败"）：当前用诊断注入验证了"托盘不可用 → 关窗 → 进程退出"的进程行为（L1 注入 + L3 进程观察）；真实 `Shell_NotifyIcon` 失败（重建 Explorer / 无 shell 会话）未构造，矩阵保留未验证并写清解除条件。
3. **登录自启（S0-AUTO-02）**：未做注销/重启验证。
4. **任务栏浅色/深色实际视觉**：像素断言覆盖语义色与 alpha，但未在真实任务栏上做浅色反色截图对照（抓屏管线在锁屏下不可信）。

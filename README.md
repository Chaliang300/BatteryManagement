# PowerDock

PowerDock（BatteryManagement）是面向 Windows 的桌面电量中心设计。计划离线汇总蓝牙、2.4G/USB HID、本机电池及受支持的厂商设备，通过桌面挂件、主窗口和系统托盘展示电量。

当前处于文档阶段，可在浏览器打开 [HTML 原型](docs/mockup/index.html) 查看方案 A 的主窗口和三档挂件。原型使用演示设备数据。WPF 应用、构建打包脚本与测试会从 S0 开始建立。
